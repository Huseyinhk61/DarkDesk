# Getting started with DarkDesk

## Install

Download **DarkDesk-Setup-<version>.exe** from the [latest stable release](https://github.com/Huseyinhk61/DarkDesk/releases/latest). Open the file and follow the wizard. No Node.js/npm setup is needed. For Linux, choose the DEB or AppImage and follow the [Linux guide](LINUX.md).

GitHub's automatically generated **Source code (zip)** contains project sources. AppX/Store submission packages are publisher files. The Setup EXE is the normal Windows download.

## Organize your first items

1. Open **System Scanner → Desktop** and scan.
2. Review categories in Smart Groups. Change an item's category or drag it onto a group.
3. Choose Move or Copy in Settings, then select Organize and review the preview.
4. Confirm only the changes you want. Undo is available in the result notification and operation history.

For **Installed apps** and chosen application folders, DarkDesk creates category shortcuts instead of moving installed program files. A scan discovers files; it does not organize them until you confirm a plan. Existing target files and conflicts are shown before confirmation.

## Personalize

- Change theme, font, size, language and motion in **Settings → Appearance & language**.
- Open **Categories & Rules → Customize** on a category for folder color, style and icon. **Save and apply to Desktop** applies its physical Windows folder artwork; existing personal folder icons may be preserved.
- Use Workspace Profiles for focus modes. **Ctrl+Alt+0** restores Default Mode; change key assignments under Global shortcuts.

## Your daily tools

Press **Alt+X** for Quick Launcher. Type `?` for help, `calc 12 * 5` to calculate, `g query` to search, or `1 usd tl` to convert currency. Pin favorites for easier access. Choose a default conversion target and saved pairs in Currency Converter.

Open **Desktop Widgets** to show notes, tasks, clock, focus timer, system readings or weather. Notes and tasks use pages; use Previous/Next for longer content. Widgets keep their state through a normal restart. Weather setup and forecast limits are described in the [weather guide](WEATHER.md).

## Close or update

Closing the main window can leave DarkDesk in the system tray. Choose **Exit** from the tray to quit completely. Windows Setup and Linux AppImage builds support in-app update notifications; portable and DEB builds are updated manually. Store edition updates are managed by Microsoft Store.

## Something does not work

Open **Help & Getting Started → Help & support → Copy support information**, then [report the issue](https://github.com/Huseyinhk61/DarkDesk/issues/new?template=bug_report.yml). Describe the scan source and steps; include the visible error. Support information includes version, platform, architecture, channel, language and theme. Review screenshots/logs for personal paths before posting.
