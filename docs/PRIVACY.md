# DarkDesk privacy notice

DarkDesk stores preferences, desktop operation history, notes, tasks, launcher favorites and optional local usage statistics on your device. No analytics account, advertising identifier, or DarkDesk cloud account is required. Desktop and installed-application scanning run locally. File operations happen only through your chosen organization actions or enabled automation; installed program folders are not moved.

Optional network features:

- **Currency conversion:** requests institutional reference rates from Frankfurter (`api.frankfurter.dev`). Amount calculations run locally; entered amounts and search text are not sent to this service.
- **Weather:** after you choose a location, requests a forecast from MET Norway (`api.met.no`). Rounded coordinates are sent to obtain the forecast; your note text, tasks and application list are not sent. Location is selected manually, without GPS or IP geolocation. Forecast data is attributed to MET Norway, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). [Provider terms](https://api.met.no/doc/TermsOfService).
- **Optional application descriptions:** when you explicitly request an online match, the app name is used by the configured public knowledge source. Review the in-app disclosure before using this feature.
- **Updates:** the GitHub edition checks public DarkDesk releases on GitHub. The Microsoft Store edition uses Store-managed updates.
- **Web searches:** launcher web prefixes open your selected search in your default browser; that provider's privacy policy applies.

These services receive ordinary network metadata such as your IP address. DarkDesk does not control their retention policies. Offline features remain usable when these services cannot be reached. You can disable widgets and optional tracking/automation in the application. Notes and tasks can be cleared in their widgets. To remove remaining local application data, close DarkDesk and remove its user-data directory after backing up anything you need.

Support and privacy questions: [DarkDesk issues](https://github.com/Huseyinhk61/DarkDesk/issues). Do not post private filenames, notes, credentials or personal information in public issues.
